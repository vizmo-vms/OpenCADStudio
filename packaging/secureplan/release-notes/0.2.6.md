SecurePlan CAD 0.2.6 fixes Edit in desktop on Windows. SecurePlan still works with 0.2.2, so updating is recommended but not required.

- On Windows, choosing Edit in desktop in SecurePlan opened SecurePlan CAD but did nothing, with the warning "ignored an invalid SecurePlan CAD link". Windows can pass the link on with an extra "/" (secureplan-cad://pair/?…), which SecurePlan CAD now accepts as the same link.
- If SecurePlan CAD ignores a link, the warning now says why, without showing the link itself.

Install: on macOS, open the disk image, move SecurePlan CAD to Applications, approve it once in System Settings › Privacy & Security, and open it once. On Windows, run the installer and accept the SmartScreen warning. Installed copies offer this update themselves.
