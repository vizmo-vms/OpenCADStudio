SecurePlan CAD 0.2.4 adds https://secureplan.vizmo.app as a built-in allowed website. SecurePlan still works with 0.2.2, so updating is recommended but not required.

- https://secureplan.vizmo.app is now allowed without asking, like https://secureplan.vizmo.dev. Both are listed as built in under Allowed websites and cannot be removed. Other websites still ask once, with Allow and Don't allow.
- Every website, built in or not, still connects only with the one-time secret from its own Edit in desktop launch.

Install: on macOS, open the disk image, move SecurePlan CAD to Applications, approve it once in System Settings › Privacy & Security, and open it once. On Windows, run the installer and accept the SmartScreen warning. Installed copies offer this update themselves.
