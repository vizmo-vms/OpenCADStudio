SecurePlan CAD 0.2.5 moves to Open CAD Studio 2026.40.1, with its drawing, display and editing fixes. SecurePlan still works with 0.2.2, so updating is recommended but not required.

- The plan SecurePlan receives from Apply looks the same as before: text is still drawn as outlines, and only the drawing's own content is published.
- New Open CAD Studio features that write a drawing to a file or read other files stay unavailable for a SecurePlan drawing: Write Block (WB), the new Xref attach commands, point cloud attach, PDF import and saving a node graph. Use Apply to send the drawing to SecurePlan.
- SecurePlan CAD still runs no automation server: the new --http option is refused, it loads no plugins, and it writes no crash log.

Install: on macOS, open the disk image, move SecurePlan CAD to Applications, approve it once in System Settings › Privacy & Security, and open it once. On Windows, run the installer and accept the SmartScreen warning. Installed copies offer this update themselves.
