SecurePlan CAD 0.2.0 is simpler: it works only with SecurePlan.

- A new home screen replaces the old start page. It shows the version, how to start, your connected surveys, Check for updates and Allowed websites. The home screen comes back when you close the last survey.
- Drawings open only for a survey. In SecurePlan, choose Edit in desktop, then choose Open drawing in SecurePlan CAD. If the survey already has a drawing, SecurePlan CAD asks before replacing it, and Cancel changes nothing.
- https://secureplan.vizmo.dev is allowed without asking. Other websites still ask once, with Allow and Don't allow.
- SecurePlan CAD now has the Vizmo icon and name. About lists the open-source project it is built on and where to get the source code.

Install: on macOS, open the disk image, move SecurePlan CAD to Applications, approve it once in System Settings › Privacy & Security, and open it once. On Windows, run the installer and accept the SmartScreen warning. Installed 0.1.0 copies offer this update themselves.
