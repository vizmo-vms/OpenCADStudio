SecurePlan CAD 0.2.3 keeps the app responsive when you align or apply a large drawing. SecurePlan still works with 0.2.2, so updating is recommended but not required.

- Apply and Align no longer freeze SecurePlan CAD on large drawings. Before, the app stopped responding for several seconds while it worked out what the drawing shows, before the Align or Apply dialog appeared.
- While SecurePlan CAD checks the drawing, a "Checking the drawing" window shows how long it has taken. Cancel or Escape closes it and nothing changes. The Align or Apply dialog opens as soon as the check finishes, using the drawing as it was when you chose Apply or Align.

Install: on macOS, open the disk image, move SecurePlan CAD to Applications, approve it once in System Settings › Privacy & Security, and open it once. On Windows, run the installer and accept the SmartScreen warning. Installed copies offer this update themselves.
